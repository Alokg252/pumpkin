<h1>Injtellij Idea Features</h1>
___

- `ctrl+.` show fixes and modification
- `double shift` to search current words
- type `case` in find windows to see case changes

___

- `ctrl+shift+p` optimist search about anything i did for `All, Classes, Files, Symbols, Actions, Text` i did `about` in `Actions`
- above point also has scope where to find `in project`, `anywhere`
- in `Clsses` press `ctrl+k, ctrl+i` for class preview
- `ctrl+shift+o` look for method (Symbols)
- `ctrl+p` look for a file (Files)

___

- <small><code style="color:coral; background-color:#444; padding:1px 2px; border-radius:5px;">ctrl+i</code></small> to see lookup menu again (menu of suggestions)
- `alt+shift+right-arrow` select word `right-arrow` again can will increase search area like 
	1. select word
	2. select whole string
	3. select "" also 
	4. select whole method call 
	5. abd will continue 

___

- `f2` to change variable names and intellij will detect  getter, setter and other things to change
- `ctrl+alt+v` to change values from its variable name eg. String s = "java" then all "java" can be replaced with s
- <small><code style="color:coral; background-color:#444; padding:1px 2px; border-radius:5px;">ctrl+alt+m</code></small>  to extract method or function 

___

- `ctrl-shift-r` to perform refactoring actions, take as parameter, create inline variable, create variables or constants of hardcoded values etc.
-  `ctrl+k, ctrl+c` to comment, uncomment code lines and blocks
- `alt+shift+a` to comment, uncomment code blocks with `/*....*/` 

---

- `ctrl+shift+k` to delete current line
- `ctrl+shift+[` collapse code block
- `ctrl+shift+]` expand code block
- `ctrl+k, ctrl+0` collapse all
- `ctrl+k, ctrl+j` expand all
- `ctrl+alt+t` surround selected code fragment with some template code eg. If, for, while, try-catch, Synchronised, Runnable etc.
- `ctrl+shift+delete` to unwrap from any surrounded template code eg. If, for, while etc.

---

- `ctrl+shift+p -> push`  to push the commits 
- `ctrl+shift+g`  project commits graph history 
- `alt+m` to start Ammend last not pushed commit
- interactive rebase is awesome
  1. See graph history
  2. Right click and select interaction rebase from here on the required commit
  3. Arrange, drop, pick, select multiple and squash to merge multiple commits in one and new commit message 
  4. After performing all operations `ctrl+enter` and press `start rebasing` and Done!
- shelve changes to escape those changes from commit and only stay in local

---
⭐ `ctrl+shift+'` to pull up the bottom bar
⭐ `ctrl+shift+e` hide side tool windows
